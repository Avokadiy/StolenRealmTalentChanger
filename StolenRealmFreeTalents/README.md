# StolenRealm Free Talents Mod

Мод для игры Stolen Realm, который позволяет менять таланты в любой момент без необходимости сбрасывать атрибуты и таланты.

## Описание

В оригинальной игре смена талантов требует полного сброса характеристик персонажа. Этот мод убирает данное ограничение, позволяя свободно перераспределять таланты через интерфейс тренировки (Trainer).

## Установка

1. Найдите папку с игрой Stolen Realm
2. Скопируйте файл `FreeTalents.dll` в папку модов игры (обычно это `BepInEx/plugins/` или аналогичная)
3. Убедитесь, что у вас установлен BepInEx или другой совместимый загрузчик модов

## Требования

- BepInEx 5.x или новее
- UnityDoorstop (обычно идет в комплекте с BepInEx)

## Как использовать

После установки мода:
1. Запустите игру
2. Найдите тренера (Trainer) в игре
3. Теперь вы можете менять таланты без сброса всех характеристик

## Сборка

Для сборки мода вам понадобится:
- .NET SDK 6.0 или новее
- Reference assemblies из игры Stolen Realm

```bash
dotnet build
```
