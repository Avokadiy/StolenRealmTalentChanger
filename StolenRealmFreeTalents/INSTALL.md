# Инструкция по установке мода StolenRealm Free Talents

## Что делает этот мод

Мод позволяет менять таланты персонажа в любой момент без необходимости полного сброса характеристик (attributes). В оригинальной игре при изменении талантов требуется сначала сбросить все атрибуты, что неудобно. Этот мод убирает данное ограничение.

## Требования

1. **BepInEx 5.x** - фреймворк для моддинга Unity игр
2. **Stolen Realm** - игра должна быть установлена

## Шаг 1: Установка BepInEx

### Вариант А: Автоматическая установка (рекомендуется)

1. Скачайте BepInEx с официального GitHub: https://github.com/BepInEx/BepInEx/releases
2. Распакуйте архив в папку с игрой Stolen Realm
3. Запустите игру один раз - BepInEx создаст необходимые конфигурационные файлы

### Вариант Б: Использование менеджера модов

Если вы используете менеджер модов (например, r2modman), просто установите BepInEx через него.

## Шаг 2: Сборка мода

### Предварительные требования

- .NET SDK 6.0 или новее: https://dotnet.microsoft.com/download
- Исходный код игры (Assembly-CSharp.dll) из папки Stolen Realm

### Процесс сборки

1. Скопируйте `Assembly-CSharp.dll` из папки игры:
   ```
   <Путь к игре>/StolenRealm_Data/Managed/Assembly-CSharp.dll
   ```
   
2. Создайте папку `lib` в директории проекта:
   ```bash
   mkdir lib
   ```

3. Скопируйте DLL файл в папку lib:
   ```bash
   cp "<Путь к игре>/StolenRealm_Data/Managed/Assembly-CSharp.dll" lib/
   ```

4. Соберите проект:
   ```bash
   dotnet build --configuration Release
   ```

5. Готовый файл мода будет находиться в:
   ```
   bin/Release/net6.0/FreeTalents.dll
   ```

## Шаг 3: Установка мода

1. Найдите папку BepInEx/plugins в директории игры:
   ```
   <Путь к игре>/BepInEx/plugins/
   ```

2. Создайте папку для мода (опционально):
   ```
   <Путь к игре>/BepInEx/plugins/FreeTalents/
   ```

3. Скопируйте файл `FreeTalents.dll` в эту папку

## Шаг 4: Проверка работы

1. Запустите игру
2. Откройте лог BepInEx (обычно находится в `<Путь к игре>/BepInEx/LogOutput.log`)
3. Найдите строки:
   ```
   [FreeTalents] FreeTalents mod loaded successfully!
   [FreeTalents] You can now change talents without resetting attributes.
   ```

4. В игре найдите тренера (Trainer) и попробуйте изменить таланты
5. Если мод работает correctly, вы сможете менять таланты без сообщения о необходимости сброса атрибутов

## Решение проблем

### Мод не загружается

1. Убедитесь, что BepInEx установлен правильно
2. Проверьте LogOutput.log на наличие ошибок
3. Убедитесь, что версия .NET соответствует требованиям

### Ошибки сборки

1. Убедитесь, что Assembly-CSharp.dll скопирован в папку lib
2. Проверьте версию Unity в игре (может потребоваться изменить версию UnityEngine.Modules в .csproj)

### Мод загружается, но не работает

1. Включите подробное логирование в конфиге BepInEx
2. Проверьте логи на сообщения от FreeTalents
3. Возможно, имена методов в вашей версии игры отличаются - потребуется декомпиляция Assembly-CSharp.dll для уточнения имен методов

## Декомпиляция игры для поиска правильных имен методов

Если мод не работает, возможно имена классов/методов отличаются в вашей версии игры:

1. Скачайте dnSpy или ILSpy
2. Откройте файл `Assembly-CSharp.dll` из папки игры
3. Найдите классы связанные с:
   - Character (персонаж)
   - Talent (таланты)
   - Trainer (тренер)
   - Reset (сброс)
   - Attribute (атрибуты)

4. Обновите имена классов и методов в файле FreeTalents.cs

## Дополнительная помощь

Если у вас возникли проблемы:
1. Проверьте логи BepInEx
2. Убедитесь, что другие моды работают (если есть)
3. Попробуйте отключить другие моды для проверки совместимости

## Откат изменений

Чтобы удалить мод:
1. Удалите файл `FreeTalents.dll` из папки `BepInEx/plugins/`
2. Перезапустите игру
